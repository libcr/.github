## What We Build

We use libcr to build fast, secure, and cross-platform desktop applications in modern C++,
using Chromium's production-grade platform technologies.
Such as Remote desktop application, GPU-accelerated video player with interactive HTML5 interface, 
chrome-style file manager with Android QuickShare support, document workflows, and technical content. Our applications
combine native Chromium Views interfaces with Chromium components
such as the WebRTC, Nearby Protocol, Network Service, Chromium Media, GPU, WebContents, Crashpad and PDFium.

This approach gives our software the capabilities of the Chromium platform
while retaining native C++ performance, efficient system integration, and
fine-grained control over application architecture.
